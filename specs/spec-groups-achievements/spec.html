Key business & permission rules (decisiones.md & §5.9)

  • Split write permissions (§4.4 / §6.1.1):
  • groups: read by member+ and anonymous (/public/groups*); write (POST/PATCH/DELETE /groups*, logo, image) by board and admin ONLY (403 for member and technical).
  • achievements: read by member+ and anonymous (/public/achievements); write (POST/PATCH/DELETE /achievements*, logo) by technical, board, and admin (403 for member).
  • Own group protection: groups_single_own enforces at most one isOwn = true row (409 duplicate if attempting to create or patch a second isOwn = true). Deleting the own group (isOwn = true) is forbidden (409 in_use / 422).
  • Validation: faixa, shirt, and trousers arrays must contain valid #RRGGBB hex colors (422 validation_failed); website and socialLinks URLs validated when non-null; foundation and achievement.year reasonable positive integers.
  • Derived fields on Group (§5.9):
  • eventIds: IDs of published events where this group appears in event_groups.
  • achievementIds: IDs of achievements belonging to this groupId (ordered by year DESC, title).
  • memberIds: populated only on the own group (isOwn = true) and only with users satisfying status = active && consent.publicProfile == true && !isMinor (empty array [] on guest groups).
  • Public routes (Cache-Control: public, max-age=300): GET /api/v1/public/groups, GET /api/v1/public/groups/{id}, and GET /api/v1/public/achievements (with optional ?groupId= and ?year= filters). Group and achievement images/logos are public via FileAccessPolicy.

Sections

Derived Group relations & RGPD compliance (§5.9)

Contents

Every Group response includes eventIds (only published = 1 events linked via event_groups), achievementIds, and memberIds.

Behavior

memberIds is computed only when group.isOwn == true and strictly filters to users with status = 'active', consent_public_profile = 1, and !isMinor (in Europe/Madrid). Guest groups always return memberIds = [].

Hex colors, social links & media uploads

Contents

faixa, shirt, and trousers are JSON string arrays in SQLite validated against ^#[0-9A-Fa-f]{6}$. socialLinks validates optional instagram, facebook, x, youtube URLs/handles.

Behavior

Logo and image endpoints (PUT/DELETE) delegate to FileStorageService (max 10 MB, JPEG/PNG/WebP, subject to upload rate limit) and remove replaced files from FILES_DIR post-commit.
