Overview

Completes what platform-server-auth leaves open (RGPD export, consent hardening, full self-profile editing) and connects it to the web management shell.

Source of truth: docs/especificacion-tecnica.md v1.3 §5.4, §6.7 (/me/export), §7.3 · docs/decisiones.md (RGPD).

Prerequisites

  • platform-server-infra, platform-schema-v02, platform-core-contract
  • platform-server-auth: Bearer session, GET/PATCH /me, ConsentRequiredPlugin (allowlist already includes /me/export)
  • platform-web-shell: GIS login, SessionManager, AuthViewModel, AppNavigation

Behaviour summary (decisiones.md)

  1. After login, if consent.dataProcessing == false, webapp navigates to setup (/configuracio-inicial) until the user (or tutor text in signedBy for minors) accepts privacy policy via PATCH /me.
  2. Any API call returning 403 consent_required redirects the webapp to /configuracio-inicial.
  3. GET /me and GET /me/export return self-visible data including emergencyContact, isMinor, notes, and (when minor) guardians. GET /me/export additionally bundles orgRoles, positions, own attendance, active sessions (no hashes), and metadata of documents linked to userId = me (e.g., signed consent PDFs).
  4. Profile screen edits only §5.4 self fields (using PatchField<T> + version) and provides a download button saving muixeranga-dades-YYYY-MM-DD.json via browser Blob download.

Acceptance (slice)

Structure

End-to-end RGPD flow:

Login (platform-web-shell)
  → AuthViewModel loads GET /api/v1/me
  → if !me.consent.dataProcessing → redirect /configuracio-inicial (ConsentSetupScreen)
  → user accepts → PATCH /api/v1/me → AuthViewModel refreshes Me → navigate home

ProfileScreen (/el-meu-perfil)
  → Save → validate (:core) → PATCH /api/v1/me (with version & PatchField)
  → Export → GET /api/v1/me/export → BrowserFileDownload.downloadBytes(...)

MeExportResponse JSON structure (formatVersion = 1):

  • exportedAt: UTC Instant
  • formatVersion: 1
  • user: UserSelf (includes consent, account self-safe, emergencyContact, isMinor, guardians if minor, notes, orgRoles)
  • positions: list of UserPositionSummary for this user
  • attendance: list of own Attendance rows
  • documents: list of own Document metadata (id, title, kind, date, file, notes, createdAt) where user_id = me
  • sessions: list of SessionSummary (no token hashes)

Sections

Consent setup rules (server + web)

Contents

Screen title «Configuració inicial». Displays a link to the privacy policy (https://muixerangadelx.com/privacitat, overridable via compile-time config), a mandatory checkbox for consent.dataProcessing, and a signedBy input (defaulting to the user's name; for minors, copy explicitly states that a legal guardian must sign and enter their name).

Behavior

Submit is disabled until dataProcessing is checked and signedBy is non-blank. On PATCH /me, the server rejects setting dataProcessing from true back to false (422 validation_failed), requires signedBy when transitioning false -> true, and stamps signedAt server-side with current UTC Instant whenever consent flags change if the client omitted it. On success, ProfileRepository notifies AuthViewModel so the consent gate unlocks immediately.

Minor visibility consistency (`decisiones.md`)

Contents

Both GET /me and GET /me/export follow the exact same self-visibility rule: the authenticated user sees emergencyContact, isMinor, notes, and (when isMinor == true) their guardians list.

Behavior

Neither GET /me nor GET /me/export exposes board-only fields (documentId, memberNumber, leftAt, birthDate) or server-only tables (google_identities, refresh_tokens).

Profile editing and download (`ProfileScreen`)

Contents

«El meu perfil» renders the navy hero banner (avatar, name, nickname, badges, «Canvia la foto» wired once platform-files lands) above a 2-column layout (stacked on mobile): left column has 3 bordered white cards — Informació personal (malnom, telèfon, carrer i número, codi postal, ciutat, sobre mi, talla de camiseta, talla de pantaló, idioma de la interfície preferredLocale), Contacte i emergència, and Privacitat i dades (switches Perfil públic a la web, Drets d'imatge, Grup de WhatsApp + callout box «Descarrega les meues dades») with red DESA button; right column shows the yellow-top-bordered Informació de només lectura card («Per a canviar-ho, parla amb la junta»: Nom, Cognoms, Data de naixement, Estat, Tipus de membre, Càrrecs actuals, plus notes and guardians if minor).

Behavior

Sends only changed fields (including preferredLocale) via PatchField<T> + version. On 409 version_conflict, shows «Algú ha modificat aquest element mentre l'editaves» with a «Recarrega» action. Clicking «Descarrega les meues dades» calls GET /api/v1/me/export and downloads muixeranga-dades-YYYY-MM-DD.json via BrowserFileDownload.
