Overview

First delivery slice for the Muixeranga management API. Turns the current scaffold (GET / hello on 0.0.0.0) into a production-shaped JVM 21 process: read env per docs/especificacion-tecnica.md §9.1, bind APP_HOST (default 127.0.0.1), enforce NFR-03/05/06/10, expose GET /api/health without auth, and install cross-cutting plugins future routes will reuse.

Source of truth: docs/especificacion-tecnica.md v1.3 §6.1, §6.3, §8, §9.1 · docs/decisiones.md (Google OIDC + own sessions later — not Firebase).

Goals

  • Fail fast on startup when mandatory env vars are missing or JWT_SECRET has fewer than 32 decoded bytes.
  • GET /api/health → 200 {"status":"ok","version":"…","db":"ok"} or 503 if SQLite fails SELECT 1.
  • Unified JSON error envelope per §6.3 (code, message in Valencian, optional fields, optional current), using :core ApiErrorResponse once available or created minimally in :core and extended by platform-core-contract.
  • Enforce 1 MB body limit for JSON requests (NFR-05), exempting multipart upload routes configured later in platform-files.
  • Trust X-Forwarded-For / X-Forwarded-Proto only when the direct peer is 127.0.0.1 (Caddy reverse proxy, §6.10).
  • CORS configured from CORS_ORIGINS with allowCredentials = true (never * with credentials) plus open GET CORS without credentials for /api/v1/public/*.
  • Single-writer SQLite connection + concurrent reader connections under WAL with foreign_keys = ON and busy_timeout = 5000 (NFR-03).
  • Sanitized CallLogging: one line per request (method, path, status, durationMs, userId from a shared AttributeKey populated by auth slice) — never tokens, cookies, or request bodies.
  • Graceful shutdown on SIGTERM closing Netty and SQLite pools cleanly (NFR-10).

Sections

Environment validation rules (§9.1)

Contents

Mandatory variables checked on startup: DB_PATH, FILES_DIR, JWT_SECRET, GOOGLE_CLIENT_IDS, PUBLIC_BASE_URL, CORS_ORIGINS. Optional variables with defaults: APP_PORT=8080, APP_HOST=127.0.0.1, JWT_SECRET_PREVIOUS=null, GOOGLE_JWKS_URL=https://www.googleapis.com/oauth2/v3/certs, COOKIE_DOMAIN=null (omitted in local dev → host-only cookie), ENABLE_API_DOCS=true, BOOTSTRAP_ADMIN_EMAIL=null, DIPU_CATALOG_LIMIT=5, LOG_LEVEL=INFO.

Behavior

Validate JWT_SECRET has at least 32 raw bytes (attempt Base64 decode first; if valid Base64 use decoded length, else UTF-8 byte length; fail clearly if < 32). For local runs, developers supply a .env file or env vars; there are no silent insecure defaults for JWT_SECRET or GOOGLE_CLIENT_IDS in production startup. Tests inject EnvConfig directly via constructor.

SQLite concurrency pool (NFR-03)

Contents

Wrap openDatabase() in DatabaseAccess exposing read { } (bounded reader pool on Dispatchers.IO) and writeTransaction { } (serialized single-writer connection/mutex on Dispatchers.IO) so concurrent requests never hit SQLITE_BUSY write races while reads stay fast.

Behavior

Every connection enables PRAGMA foreign_keys = ON, journal_mode = WAL, and busy_timeout = 5000. On ApplicationStopped / SIGTERM, drain and close connections cleanly.

Logging and error contract (NFR-06, §6.3)

Contents

Logback outputs plain text lines to stdout (captured by journald) respecting LOG_LEVEL. Format includes HTTP method, path (without query secrets), status, duration in ms, and call.attributes.getOrNull(RequestUserIdKey) ?: "-".

Behavior

Never log Authorization, Cookie, Set-Cookie, or request/response bodies. StatusPages maps BadRequestException / SerializationException → 400 invalid_json, AppException → its status/code/fields/current, and any unhandled Throwable → 500 internal_error (stack trace logged server-side only, never returned to client).
