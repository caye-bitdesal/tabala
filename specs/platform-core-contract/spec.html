Serialization & contract rules (decisiones.md)

  • Shared TabalaJson = Json { ignoreUnknownKeys = true; explicitNulls = false } used by both Ktor server and MuixerangaApi.
  • Money (MoneyCents): @JvmInline value class MoneyCents(val cents: Long) with custom KSerializer encoding/decoding JSON numbers in euros with 2 decimal places (450.00 ↔ 45000L, never Double arithmetic).
  • RFC 7386 Merge Patch (PatchField<T>): sealed interface Absent | Null | Value(val value: T) with custom serializer so PATCH requests distinguish omitted fields (untouched) from explicit null (clear field) even when explicitNulls = false.
  • Enums: @SerialName("snake_case") wire values per §5.3, with MemberStatus = active, inactive, on_leave, deleted (replaces former).
  • Dates/times: datetime → kotlinx.datetime.Instant; date → kotlinx.datetime.LocalDate.
  • Derived fields (orgRoles, vacant, totalQuantity, lowStock, overdue, isMinor, googleLinked, etc.): present on response DTOs; omitted on create/patch request DTOs.

DTO naming convention:

  • FooPublic: strictly filtered subset for /api/v1/public/*.
  • FooCreate: POST request body (no id, version, timestamps, or derived fields).
  • FooPatch: RFC 7386 Merge Patch body with required version: Int and PatchField<T> properties.
  • PagedResponse<Foo>: §6.2 pagination envelope (items, page, perPage, totalItems, totalPages).

Sections

MoneyCents serialization (`decisiones.md`)

Contents

Represent monetary amounts as @Serializable(with = MoneyCentsSerializer::class) @JvmInline value class MoneyCents(val cents: Long) instead of Double.

Behavior

Serializer emits an exact JSON number with 2 decimal digits via JsonUnquotedLiteral (e.g. 45000L → 450.00) and parses JSON numbers (450, 450.5, 450.00) strictly to integer cents (rejecting >2 decimal places or non-numeric strings with SerializationException). Reject negative values in validators.

PatchField<T> for RFC 7386 Merge Patch

Contents

Every optional field in *Patch DTOs uses PatchField<T> defaulting to PatchField.Absent. Explicit JSON null deserializes to PatchField.Null (clear value); a non-null JSON value deserializes to PatchField.Value(v).

Behavior

Custom serializer + TabalaJson omits Absent keys when encoding from client, writes explicit null for PatchField.Null, and writes the encoded value for PatchField.Value. On the server, services apply updates only for non-Absent fields, preventing accidental wipes.

Value types and permissions (§6.1.1)

Contents

Include FileRef(id, url, thumbUrl?, contentType, size), GeoPoint(latitude, longitude), PostalAddress, EmergencyContact, UserConsent, UserAccount, UserGuardian, OrgRoleSummary, UserPositionSummary, SocialLinks, ContractClient, ContractContact, ContractGrant, ContractBilling, InventoryVariant, AttendanceSummary.

Behavior

Expose Permission string constants matching all 21 rows in §6.1.1 plus permissionsForRole(role: AccountRole): Set<String> so server (GET /me) and client navigation share a single source of truth.

Enum labels in Valencian (§12.3)

Contents

Provide labelCa(): String for all 20 enums in §5.3.

Behavior

Match §12.3 verbatim, plus MemberStatus.DELETED -> "Eliminat", AreaKind.BOARD -> "Junta directiva", AreaKind.AREA -> "Àrea", and ShirtSize (XS..XXXL, Infantil 4..Infantil 14).
