Overview

Foundation UI slice before feature specs (organigrama, calendari…). Replaces the demo App() with the real admin shell talking to platform-server-auth via MuixerangaApi.

Source of truth: docs/especificacion-tecnica.md v1.3 §7.1–7.3, §7.5 · docs/decisiones.md (Navigation 2, Google GIS, no Firebase, wasmJs only in v1).

Prerequisites

  • platform-server-infra + platform-server-auth running locally on http://localhost:8080 (same-site with webpack dev server on http://localhost:<port> so SameSite=Strict cookies work).
  • platform-core-contract: MuixerangaApi, auth DTOs, Permission constants.
  • platform-me-rgpd plugs into /configuracio-inicial and /el-meu-perfil (this slice registers routes and exposes AuthViewModel.onMeUpdated(MeResponse)).

Acceptance (slice)

  • ./gradlew :app:webApp:wasmJsBrowserDistribution :app:shared:jvmTest succeeds.
  • Manual E2E: /entra → GIS login with nonce → token in RAM only (zero localStorage/sessionStorage token storage) → GET /me → home with tabs filtered by permissions.
  • Reload any deep link (/calendari, /contractacions) → silent /auth/refresh (credentials: include) → preserves route and session.
  • Logout → revokes session, calls google.accounts.id.disableAutoSelect(), clears backstack and replaces browser history so browser «Back» cannot return to protected UI (§10.2).
  • technical sees /configuracio (via achievements:write or config:write); member does not.
  • Auth errors not_invited / account_disabled display exact §7.3 Valencian copy.
  • Non-WasmGC browsers display a readable Valencian HTML fallback message before Wasm fails (§7.1).

Sections

Local dev origin & API_BASE_URL injection

Contents

Gradle injects API_BASE_URL into index.html <meta name="tabala-api-base-url"> via processResources token replacement (default http://localhost:8080/api/v1 in dev; -PapiBaseUrl=https://api.muixerangadelx.com/api/v1 for production distribution).

Behavior

Using http://localhost (never 127.0.0.1) for both webpack dev server and Ktor server ensures cookies are same-site (SameSite=Strict) and matches Google Cloud OAuth authorized origins (§4.6).

GIS overlay & WasmGC fallback (§7.1)

Contents

index.html runs a small inline WasmGC capability check before loading webApp.js; unsupported browsers immediately see a clear Valencian HTML message instead of a blank screen. When Compose is mounted, #google-signin-overlay is shown centered over the login card slot only when AuthUiState is LoggedOut.

Behavior

GoogleSignInBridge generates a fresh random nonce per sign-in attempt, passes it to google.accounts.id.initialize, and forwards both credential and nonce to AuthViewModel → POST /api/v1/auth/google. Clicking «Prova amb un altre compte» calls disableAutoSelect() and re-renders the button.

Protected binary fetch helper (for images & files)

Contents

Provide a reusable helper on SessionManager / MuixerangaApi (fetchAuthorizedBytes(url): ByteArray) that sends Authorization: Bearer (with automatic 401 refresh retry) so later feature slices (members, inventory, documents) can render protected images via Compose ImageBitmap and trigger Blob downloads.

Behavior

Public URLs can load normally; protected /api/v1/files/* assets never rely on cookies or unauthenticated <img> tags.

Shared design system & Valencian formatting (§7.2, §7.5 & mockups)

Contents

Bundle Roboto .ttf weights (Regular, Medium, Bold) in app/shared/src/commonMain/composeResources/font/ and provide DateTimeFormatCa (Europe/Madrid, ca-ES) and MoneyFormatCa (450,00 €) helpers. Follow the official mockup visual system (decisiones.md): red (#BB2029) top header, yellow (#FFC432) active indicator, navy (#14005E) user pill & selected KPI accent, light-grey KpiFilterStrip, RightSideSheet for entity editing, and CenteredFormModal for creation/quick actions.

Behavior

Centralize all shell copy in Valencian resources (structured cleanly for preferredLocale support). Ensure the top-right user dropdown menu renders in a high z-index popup layer above page CTAs. On mobile (<600 dp), render the compact red bar, horizontal scrollable KPI cards, red + FAB, and 4-tab bottom bar with «Més» sheet/menu for secondary destinations (Organigrama, Inventari, Figures, Documents, Configuració).
