Configuració colla & Logros (UI web)

Complete web UI for /configuracio: own colla editor (logo, photo, #RRGGBB clothing colors, GeoPoint, website, social links), guest colles CRUD (board/admin), and Achievements (Fites / Logros) CRUD accessible to technical, board, and admin. Web only (consumes backend from spec-groups-achievements).

Overview

Fase 3 web UI slice implementing the /configuracio section on top of the complete groups and achievements backend built in spec-groups-achievements.

Source of truth: docs/especificacion-tecnica.md v1.3 §4.4, §5.9, §6.1.1, §7.4 (Configuració) · docs/decisiones.md.

Prerequisites

  • spec-groups-achievements (all /api/v1/groups*, /api/v1/achievements*, and :core MuixerangaApi extensions).
  • platform-web-shell (/configuracio route gated by config:write || achievements:write).
  • spec-03-calendar (optional event picker when linking an achievement to an event).

Role-aware UI rules (decisiones.md)

  • board / admin (config:write + groups:write + achievements:write): sees all 3 subsections inside /configuracio — La nostra colla (edit own group), Altres colles (guest colles CRUD), and Fites / Logros (achievements CRUD).
  • technical (achievements:write, without groups:write/config:write): enters /configuracio from the navigation bar, sees Fites / Logros with full create/edit/delete/logo actions, and either sees colla info in read-only mode or defaults directly to the Fites tab (no group write controls rendered).
  • member: /configuracio is hidden from navigation and blocked by route guard.

Acceptance (slice)

  • ./gradlew :app:shared:jvmTest :app:webApp:compileKotlinWasmJs passes.
  • board/admin can edit own colla (name, subtitle, foundation, history, contact, location, #RRGGBB swatches for faixa/shirt/trousers, website, socialLinks, logo & image upload/delete) and manage guest colles (cannot delete own colla).
  • technical, board, and admin can create, edit, delete, and upload logos for achievements (with optional groupId and eventId links).
  • Client-side validation rejects invalid #RRGGBB hex colors before submitting and handles 409 version_conflict with reload prompt.

Sections

Hex color swatch editor (`faixa`, `shirt`, `trousers`)

Contents

Reusable Compose component showing visual color chips for each #RRGGBB entry with add/remove controls and instant validation against :core hex validator.

Behavior

Validates #RRGGBB format on input and normalizes uppercase hex before sending PatchField updates.

Role-based tabs (`technical` vs `board`/`admin`)

Contents

ConfigViewModel derives canEditGroups = Permission.GROUPS_WRITE in permissions and canEditAchievements = Permission.ACHIEVEMENTS_WRITE in permissions.

Behavior

For technical (canEditAchievements && !canEditGroups), opens directly on Fites and hides all group create/edit/delete/upload actions. For board/admin, opens on La nostra colla with full access to all 3 tabs.
