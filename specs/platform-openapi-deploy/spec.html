Overview

Closing Fase 1 base delivery artifacts: external clients and Astro get a verified OpenAPI 3.1 contract, operators get a readable Swagger UI without Bearer friction, and main deploys safely only when all tests pass.

Source of truth: docs/especificacion-tecnica.md v1.3 §6.1, §8 (NFR-01), §9.2–9.5, §10.1.6 · docs/decisiones.md.

Prerequisites

  • platform-server-infra (GET /api/health, ENABLE_API_DOCS defaulting to true).
  • platform-server-auth (/api/v1/auth/*, /api/v1/me*).
  • Every subsequent feature slice updates openapi.yaml in the same PR (enforced by OpenApiRouteSyncTest).

OpenAPI & Swagger UI policy (decisiones.md)

  • File: server/src/main/resources/openapi/openapi.yaml (OpenAPI 3.1.0), served publicly at GET /api/v1/openapi.yaml.
  • Swagger UI (GET /api/v1/docs) is publicly open by default (ENABLE_API_DOCS=true, can be toggled off via env) and configured as read-only documentation (supportedSubmitMethods: []) so anyone can browse the contract cleanly without needing a browser Bearer token and without executing live queries against real colla data.
  • OpenApiRouteSyncTest validates YAML syntax + OpenAPI 3.1 structure and checks 1:1 parity between Ktor-registered API routes and paths/methods in openapi.yaml (excluding static Swagger UI assets and /openapi.yaml//docs themselves).

Deploy & CI policy (Tabala paths)

  • Fat JAR: ./gradlew :server:buildFatJar → server/build/libs/server-all.jar.
  • Webapp: ./gradlew :app:webApp:wasmJsBrowserDistribution -PapiBaseUrl=https://api.muixerangadelx.com/api/v1 → app/webApp/build/dist/wasmJs/productionExecutable/.
  • CI measures and logs wasm distribution transferred size against the NFR-01 15 MB guideline.
  • Path filters in deploy-web.yml watch app/webApp/**, app/shared/**, core/** (not webApp/**).
  • Secrets: DEPLOY_HOST, DEPLOY_SSH_KEY, DEPLOY_KNOWN_HOSTS only — never JWT_SECRET.

Acceptance (slice)

  • GET /api/v1/openapi.yaml returns 200 valid OpenAPI 3.1 YAML.
  • GET /api/v1/docs returns 200 Swagger UI HTML with supportedSubmitMethods: [] when ENABLE_API_DOCS=true (and 404 when ENABLE_API_DOCS=false).
  • OpenApiRouteSyncTest passes in :server:test and fails if a route is missing from openapi.yaml or vice versa.
  • scripts/deploy-server.sh (prunes releases keeping last 5, never deleting active target) and scripts/deploy-web.sh exist and are executable.
  • .github/workflows/ci.yml, deploy-server.yml, and deploy-web.yml match Tabala module paths and v1 scope (no Android block for v1).
  • docs/api.md documents external client flow (client: "native", OAuth Playground, curl examples).

Sections

Read-only public Swagger UI (`decisiones.md`)

Contents

Vendor pinned swagger-ui-dist assets (swagger-ui-bundle.js, swagger-ui.css, index.html) under server/src/main/resources/swagger-ui/ so /api/v1/docs has zero third-party CDN dependencies.

Behavior

Initialize Swagger UI with url: '/api/v1/openapi.yaml', supportedSubmitMethods: [] (disables interactive Try-it-out so no real data queries happen from docs), and validatorUrl: null. Controlled by ENABLE_API_DOCS (default true).

OpenApiRouteSyncTest parity rules (§10.1.6)

Contents

Introspect Ktor's RoutingRoot tree inside testApplication and parse openapi.yaml with a YAML/OpenAPI parser (e.g. snakeyaml or swagger-parser in testImplementation).

Behavior

Verify openapi starts with 3.1., verify every registered API (METHOD, path) exists in openapi.yaml, and verify every operation in openapi.yaml exists in Ktor (excluding /api/v1/openapi.yaml, /api/v1/docs, and static asset routes). Fail with an explicit diff listing missing/extra operations.

Safe deployment & rollback (§9.3)

Contents

scripts/deploy-server.sh requires DEPLOY_HOST, checks server/build/libs/server-all.jar exists, uploads to /opt/muixeranga/releases/app-YYYYMMDD-HHMM.jar, updates /opt/muixeranga/app.jar, restarts muixeranga, polls https://api.muixerangadelx.com/api/health up to 60 s, and prunes older jars keeping the 5 most recent (never deleting the active symlink target).

Behavior

Exit non-zero immediately if any step or health poll fails. Document one-line manual rollback (ln -sfn /opt/muixeranga/releases/<prev>.jar /opt/muixeranga/app.jar && sudo systemctl restart muixeranga) in docs/api.md.
